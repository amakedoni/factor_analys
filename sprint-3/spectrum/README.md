# Спектр · Третий спринт

Откройте `index.html` в браузере. «Спектр» генерирует тестовые сделки, показывает портфель, принимает выгрузки калькулятора и оценивает денежные потоки по базовой и стрессовым кривым. Готовый HTML работает локально.

## Сценарная оценка

В разделе «Сценарная оценка» нажмите «Загрузить совместный пример». Он показывает синтетическую сделку на 31.07.2026. Пара CSV получена расчётом `cfcore` на сделке из генератора «Спектра». Файл кривых получен из демонстрационного режима интерфейса второй команды. Источник модулей — [общий репозиторий, коммит 2909af2](https://github.com/EconomCapital322/econom-capital/tree/2909af2dfeee768c05781c04421729725f8d055b).

У этой сделки приведённая стоимость по базовой кривой равна 98 119,01 руб. Параллельный сдвиг вверх даёт 96 063,52 руб. и изменение −2 055,49 руб. В таблице видны все семь сценариев, результат можно сохранить в CSV.

## Сквозной расчёт на своём портфеле

1. **Выгрузите вход.** После генерации откройте «Состав портфеля» и нажмите «CSV для калькулятора». Для одной сделки откройте её карточку и выберите «CSV сделки для калькулятора». Исходная выгрузка «Скачать все сделки» содержит параметры для просмотра. Калькулятор принимает отдельный нормализованный CSV по контракту v1. Например, `SYN-00001` передаётся как `deal_id=1`, а схема «В конце срока» как `SIMPLE`.
2. **Рассчитайте договорные потоки.** Используйте [калькулятор первой команды](https://github.com/EconomCapital322/econom-capital/tree/main/calculator). Ниже команды для macOS и Linux из папки `calculator`. Подставьте путь скачанного CSV. Для синтетических плавающих сделок в CSV уже есть тестовый индекс и надбавка.

   ```sh
   cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
   cmake --build build --target cfcore_cli
   ./build/core/cfcore --input "/путь/spectrum_cf_deals.csv" --output-dir out/spectrum
   ```

   Команда сохраняет `deal_summary.csv`, `cashflows.csv` и `errors.csv`. Проверьте, что в `errors.csv` только заголовок. Инструкция сборки и запуска под Windows есть [в общем репозитории](https://github.com/EconomCapital322/econom-capital/blob/main/calculator/docs/cf-integration.md).
3. **Сверьте выход.** В «Денежных потоках» нажмите «Загрузить CSV» и выберите `deal_summary.csv` и `cashflows.csv` из одного расчёта. Приложение сверяет число потоков, суммы тела и процентов, конечный остаток. Можно добавить входной CSV калькулятора. Тогда «Спектр» сверит ID и начальный долг с исходными сделками, запомнит отчётную дату и учтёт сторону сделки в оценке. Это помогает заметить сделки, пропущенные калькулятором.
4. **Загрузите кривые.** В «Сценарной оценке» укажите отчётную дату потоков из `report_dttm`. При загрузке входа с одной датой она подставляется автоматически. На ту же дату выберите `curves_ГГГГ-ММ-ДД.csv`, выгруженный из [модуля кривых](https://github.com/EconomCapital322/econom-capital/tree/main/curves-module). Также можно загрузить JSON готового результата API (`result` или `standard-result` с `reportDate` и `curves`). Выберите одну сделку или всю выгрузку и нажмите «Рассчитать PV».

## Как считается PV по кривым

Даты платежей переводятся в сроки ACT/365. В JSON используются готовые дисконт-факторы в узлах. В CSV команда кривых выгружает годовые ставки в процентах, из них коэффициенты восстанавливаются по формуле `DF = exp(−r × t / 100)`. Между узлами линейно интерполируются нулевые ставки по расчётным тенорам. До первого и после последнего узла действует ставка ближайшего узла. В день оценки `DF = 1`. Платёж до отчётной даты, несовпадающие даты и расхождения сверки выводятся как ошибки оценки. Для выгрузок с нормализованным входом выплаты стороны `LIABILITY` учитываются как отток.

PV сценария складывает тело и проценты, умноженные на дисконт-факторы. `Δ к базе` — PV сценария минус PV базы. Все изменения в этой таблице относятся к дисконтированию заданного графика. Другой экран, «Факторный анализ», разлагает изменение модельной стоимости синтетического портфеля на пять факторов по методу Шепли. Оценка Economic Capital потребует согласованной методики и дополнительных входов.

## Исходники и проверка

В `src/` лежат логика генерации, расчётов и интерфейса. В `data/` находятся пример выгрузки команды 1 и файлы совместного примера. После изменения исходников пересоберите HTML из этой папки.

```sh
node --test tests/integration.test.mjs
node build.mjs
```

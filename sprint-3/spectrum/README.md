# Спектр · Третий спринт

Откройте `index.html` в браузере. Это автономная версия с исходными примерами денежных потоков команды 1. Установка пакетов и подключение к сервису для работы интерфейса не требуются.

Кнопка «?» рядом с термином открывает его пояснение. Нажмите на номер сделки в таблице или на строку фактора на графике, чтобы открыть карточку.

## Как проверить перед защитой

1. **Генератор сделок.** Кнопка «Сгенерировать портфель» запускает расчёт с заполненными параметрами. Для контрольного примера выберите профиль «Сбалансированный», поставьте 30 сделок и запустите генерацию. Тот же код генерации и те же параметры воспроизводят портфель.
2. **Состав портфеля.** После генерации откроется список сделок. На вкладке «Распределение» для примера будет 18 аннуитетных, 9 дифференцированных и 3 сделки с погашением в конце срока. По типу ставки будет 21 фиксированная и 9 плавающих. «Скачать все сделки» выгружает весь портфель в CSV. «Скачать настройки» сохраняет параметры в JSON. Его можно загрузить через дополнительные настройки генератора.
3. **Факторный анализ.** Нажмите «Открыть в анализе» на странице состава. Выберите две даты и сделки для сравнения. На графике полосы слева от нуля снижают NPV, справа — повышают. Нажмите на фактор, чтобы увидеть его значения на обе даты, разницу и объяснение вклада в NPV. Метод и необъяснённый остаток приведены в «Как рассчитаны вклады». Кнопка «Скачать отчёт» сохраняет значения NPV, вклады и остаток.
4. **Денежные потоки.** Выберите сделку № 1. В выгрузке 668 строк CF по 334 датам. Первый платёж 22.09.2022 состоит из 2 812,56 тела и 23 224,76 процентов, всего 26 037,32. На вкладке «По годам» нажмите на год, чтобы открыть платежи за него. Кнопка «Скачать все платежи» выгружает все даты выбранной сделки в CSV. Для проверки другой выгрузки загрузите два CSV из одного запуска команды 1.

Чтобы показать конкретную группу, нажмите на тип платежей, тип ставки или интервал срока во вкладке «Распределение». В таблице нажмите на ID сделки, чтобы открыть её параметры. Для плавающей ставки карточка показывает модельный индекс и надбавку. Кнопка «Скачать выборку» рядом с фильтрами выгружает все подходящие сделки.

## Обмен с командой 1

Потоки группируются по `instrument_id` и `payment_date`. `PRINCIPAL` означает погашение тела, `INTEREST` — проценты. `deal_summary.csv` содержит `instrument_id`, `opening_principal`, `total_principal`, `total_interest`, `closing_balance`, `flow_count`. Для `cashflows.csv` нужны `instrument_id`, `payment_date` (ГГГГ-ММ-ДД), `cash_flow_type`, `amount`. Дополнительные поля разрешены. Приложение сверяет число потоков, суммы тела и процентов и конечный остаток по каждой сделке. Все файлы читаются в браузере.

Выгрузка генератора — самостоятельный формат тестового портфеля с полем `instrument_id`. Ставки в CSV записаны десятичными дробями, например `0.1450` означает 14,5%. Для плавающих ставок выгружаются демонстрационный индекс и спред. Для сквозного прогона нужно сопоставить эти поля с входным форматом калькулятора команды 1 и запустить их расчёт. Подтверждённый контракт сейчас покрывает приём выходного CF. Когда команда 1 предоставит NPV, её можно подключить отдельно.

## Данные факторного анализа

NPV на экране рассчитывается для синтетических снимков одного портфеля. Модель оценивает аннуитетные, дифференцированные платежи и погашение в конце срока. Для пяти факторов просчитываются 32 комбинации параметров и вычисляются вклады Шепли. Парные эффекты измеряются относительно начала периода, а вклад Шепли уже учитывает их. Разбивка объясняет изменение внутри демонстрационной модели. Денежные потоки команды 1 показываются в отдельном разделе. Эта выгрузка содержит суммы по сделкам и платежам без результатов NPV.

## Исходники

Файлы в `src/` разделяют интерфейс, генерацию, модель NPV и разбор CSV. В `data/` лежат две исходные выгрузки команды 1. После изменения исходников соберите автономный файл командой `node build.mjs` из этой папки.

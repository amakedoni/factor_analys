# Спринт 3

## Версии программы

- [C++](factor-analysis/) генерирует портфель, строит договорные графики и рассчитывает вклад времени, ставки дисконтирования, состава и их взаимодействий. Код из [исходной ветки команды](https://github.com/Shadovv-Government/factor-analysis/tree/7a6fb0f).
- [«Спектр»](spectrum/) запускается из готового `index.html` и показывает пять вкладов методом Шепли. Чтобы запустить без Git, скачайте и распакуйте [архив](spectrum.zip).

В C++ расчёт по сгенерированным сделкам расположен в отчёте генератора в разделе «Факторный анализ изменения стоимости». В «Спектре» после генерации откройте «Состав портфеля» и нажмите «Открыть в анализе».

## Импорт CF

Пара [сводки](spectrum/data/deal_summary.csv) и [платежей](spectrum/data/cashflows.csv) содержит 44 сделки и 3 965 строк. Импорт связывает их по `instrument_id` и сверяет итоговые суммы. Для подключения расчёта базы и стресса нужен полный прогон одной сделки через калькулятор команды 1.

# Спринт 3

«Спектр» строит историю синтетических кредитных сделок, рассчитывает текущую стоимость всего портфеля по семи кривым и раскладывает изменение выбранной метрики между двумя датами. Актуальная сборка использует калькулятор команды 1 и API кривых команды 2. [Pull request № 6](https://github.com/EconomCapital322/econom-capital/pull/6)

## Запуск

Запустите Docker Desktop. Для установки нужны Docker Compose 2.20+, Node.js, Python 3.11+ (рекомендуется 3.12), Make, CMake и компилятор C++20. Из папки с проектами выполните команды.

```sh
git clone --branch feature/spectrum-portfolio-attribution https://github.com/amakedoni/econom-capital.git econom-capital-spectrum
cd econom-capital-spectrum/factor-analysis
./start.command
```

Откройте приложение на порту 8780. На пустом стенде выберите **Портфель → Рассчитать портфель**. Скрипт готовит локальное окружение, собирает калькулятор и при необходимости запускает сервис кривых. [Открыть приложение](http://127.0.0.1:8780/) · [Подробная инструкция по установке и устранению ошибок](https://github.com/amakedoni/econom-capital/blob/feature/spectrum-portfolio-attribution/factor-analysis/README.md)

## Как устроен расчёт

1. **Портфель.** Генератор создаёт историю сделок с заданными суммами, сроками, ставками и схемами погашения. В составе портфеля можно выбрать дату, найти сделку по ID и посмотреть платежи из расчёта команды 1.
2. **Сценарии ставок.** Приложение получает базовую и шесть стрессовых кривых команды 2 на ту же дату, приводит платежи к этой дате и показывает стоимость всего портфеля. ΔPV показывает разницу между стрессом и базой. График по срокам показывает, какие платежи сформировали эту разницу.
3. **Факторный анализ.** Водопад раскладывает наблюдаемое изменение на новые и выбывшие сделки, модельные вклады факторов по общим сделкам и остаток. Отдельно можно посмотреть важность факторов, их взаимодействия, нелинейные эффекты и качество модели на более поздних датах.
4. **Данные.** Здесь доступны исходные рыночные кривые, выгрузки калькулятора за каждую дату и импорт своей истории в CSV. [Методология расчёта](https://github.com/amakedoni/econom-capital/blob/feature/spectrum-portfolio-attribution/factor-analysis/docs/methodology.md)

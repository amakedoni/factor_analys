# Спринт 3

«Спектр» генерирует синтетические кредитные сделки, показывает состав портфеля и объясняет, как меняется его модельная стоимость между двумя датами.

## Запуск

Скачайте [архив «Спектра»](spectrum.zip), распакуйте его и откройте `index.html` в браузере. Если репозиторий уже скачан, откройте [spectrum/index.html](spectrum/index.html). Приложение работает локально в браузере.

1. В «Генераторе» задайте параметры или выберите готовый профиль и нажмите «Сгенерировать портфель».
2. В «Составе портфеля» откройте таблицу или распределение сделок. Таблицу и выборку по фильтрам можно сохранить в CSV.
3. Нажмите «Открыть в анализе», выберите две даты и сегмент сделок. Метод Шепли показывает вклады остатка долга, кредитной ставки, оставшегося срока, типа платежей и ставки дисконтирования.

[Настройки, исходники и инструкция пересборки](spectrum/README.md)

## Импорт CF

В разделе «Денежные потоки» можно загрузить [сводку по сделкам](spectrum/data/deal_summary.csv) и [платежи по датам](spectrum/data/cashflows.csv). В комплекте 44 сделки и 3 965 строк. «Спектр» связывает записи по `instrument_id` и сверяет суммы, число строк и конечный остаток. Для проверки сквозного сценарного расчёта нужен полный пример по одной сделке из калькулятора команды 1.

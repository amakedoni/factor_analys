# Спринт 3

«Спектр» генерирует синтетические кредитные сделки, показывает состав портфеля и объясняет, как меняется его модельная стоимость между двумя датами. Сценарная оценка использует платежи калькулятора и кривые из общего репозитория.

## Запуск

Скачайте [архив «Спектра»](spectrum.zip), распакуйте его и откройте `index.html` в браузере. Если репозиторий уже скачан, откройте `spectrum/index.html`.

В «Сценарной оценке» откройте «Загрузить совместный пример». На экране появится PV одной сделки по базовой и шести стрессовым кривым.

## Обмен с калькулятором и кривыми

1. В «Составе портфеля» скачайте CSV для калькулятора.
2. Рассчитайте его в [калькуляторе первой команды](https://github.com/EconomCapital322/econom-capital/tree/main/calculator) и загрузите `deal_summary.csv` и `cashflows.csv` в «Денежные потоки».
3. Загрузите CSV или JSON готовых кривых с той же отчётной датой и нажмите «Рассчитать PV».

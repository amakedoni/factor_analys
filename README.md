# Факторный анализ изменения Economic Capital

Материалы трёх спринтов команды «Теневое правительство».

| Спринт | Что внутри |
| --- | --- |
| [1 · Денежные потоки](sprint-1/) | Графики ANN, SIMPLE и RGM, расчёты, Python-прототип и сверка с эталонной сделкой. |
| [2 · Однофакторные опыты](sprint-2/) | Презентация по чувствительности оценки к параметрам сделки, расчётная книга и коэффициенты дисконтирования. |
| [3 · Генератор и факторный анализ](sprint-3/) | «Спектр». Генератор истории сделок, расчёт всего портфеля с калькулятором и кривыми, факторный анализ и графики. |

## Запуск «Спектра»

Актуальная версия запускается из `econom-capital` через `factor-analysis/start.command`. Программа из браузера рассчитывает платежи в ядре команды 1, загружает кривые команды 2 и разбирает изменение показателей портфеля. [Как получить и запустить сборку](sprint-3/#запуск) · [Pull request № 6 в общем репозитории](https://github.com/EconomCapital322/econom-capital/pull/6)

Автономное демо предыдущей версии можно запустить из архива. Распакуйте его и откройте `index.html`. [Скачать автономное демо](sprint-3/spectrum.zip)

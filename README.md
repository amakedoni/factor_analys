# Факторный анализ изменения Economic Capital

Материалы трёх спринтов команды «Теневое правительство».

| Спринт | Что внутри |
| --- | --- |
| [1 · Денежные потоки](sprint-1/) | Графики ANN, SIMPLE и RGM, расчёты, Python-прототип и сверка с эталонной сделкой. |
| [2 · Однофакторные опыты](sprint-2/) | Презентация по чувствительности оценки к параметрам сделки, расчётная книга и коэффициенты дисконтирования. |
| [3 · Генератор и факторный анализ](sprint-3/) | «Спектр». Генератор синтетических сделок, состав портфеля, факторный анализ по Шепли и импорт денежных потоков команды 1. |

## Где начать

Скачайте [архив «Спектра»](sprint-3/spectrum.zip), распакуйте его и откройте `index.html` в браузере. В локальной копии репозитория готовый файл лежит в `sprint-3/spectrum/index.html`. Инструкция и исходники доступны в папке [«Спектр»](sprint-3/spectrum/).

Программа принимает и сверяет два CSV с результатами расчёта денежных потоков. Сквозной запуск через калькулятор команды 1 требует согласованного входа и полного примера по одной сделке.
